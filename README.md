# Blunder

## What is Blunder?

Blunder is an Open-Source graphics engine that started as a project for my Graphics Programming course, which I've decided to keep making outside of the class. The goal of Blunder is to, while not being the best 3D software, provide a unique rendering experience where shaders can be custom-written, similar to how shader nodes are used in Blender (hence the namesake).

## Current Status

Blunder is still under development and doesn't have a stable public release. It will likely be a few more months until it is properly working, as a major part of development is coding all of the UI features alongside the 3D features Blunder is meant to provide.

There's not really a reason to use Blunder yet (it's not even usable at all), but the reason I'm making it is because it's fun! Making your own software from the ground up is an incredibly rewarding experience (and a really good portfolio piece)!
